# PROJECT-RULES.md — 프로젝트 공통 지침

> 이 문서는 프로젝트별 규칙을 작성하는 템플릿이다. 빈 항목은 확정된 규칙이 아니다.

## 적용 범위

- 대상 프로젝트: (프로젝트명을 입력)
- 공통 개발 절차·승인·검증의 정본은 `AGENTS.md`, `docs/PLANS.md`, `docs/ai-workflow/POLICY.md`를 따른다.
- OpenCode·Codex·Claude Code 모두 동일한 프로젝트 지침을 따른다.

## 프로젝트별 구현 기준

- 기술 스택 및 실행 명령: 프로젝트 내 확인 가능한 설정 파일과 실행 스크립트에서 확인한다.
- 파일 구조 및 코드 스타일: 기존 저장소 규칙을 우선한다.
- 사용자 요청 범위를 벗어난 구조 변경·의존성 교체는 별도 승인 없이 진행하지 않는다.
- 테스트·검증은 실제 실행한 명령과 결과를 작업 기록에 남긴다.

## 프로젝트별 추가 규칙

필요한 내용만 여기에 추가한다. 예: 서비스 실행 방식, 네이밍 규칙, DB 마이그레이션 정책, 변경 금지 경로.
