# ENVIRONMENT.md — 프로젝트 실행환경 지침

> 실제 비밀값은 이 문서에 기록하지 않는다. 환경변수 파일 경로는 프로젝트별로 설정한다.

## 환경변수 파일

- 프로젝트별 환경변수 파일 경로: **(프로젝트에서 확정 후 입력)**
- 파일 경로가 설정되지 않았으면 임의의 `.env` 파일을 선택하거나 생성하지 않는다.
- 실행 전에 파일 존재 및 필수 변수 **이름**만 확인한다. 값을 출력하지 않는다.
- 애플리케이션이 해당 파일을 자동 로드하는지 확인한다. 필요하면 실행 스크립트에서 안전하게 전달한다.

## 보안 및 변경 규칙

- 비밀번호·토큰·API 키·인증서·환경변수 값의 화면 출력, 로그 저장, 커밋을 금지한다.
- 환경변수 파일을 복사하거나 다른 위치에 생성하지 않는다.
- 환경변수 추가·삭제·수정이 필요하면 이름·목적·영향만 보고하고 승인받는다.
- 필수 설정 누락으로 검증할 수 없다면 해당 검증을 `NOT_RUN` 또는 `BLOCKED`로 보고한다.

## 서비스 및 검증 실행

- 개발·테스트·운영 환경의 차이는 확인된 실행 설정을 기준으로 판단한다.
- 실제로 실행하지 않은 서버·DB·외부 서비스 연결을 확인했다고 보고하지 않는다.
