# Upstream skills (installed on demand)

Matt Pocock: https://github.com/mattpocock/skills
Superpowers: https://github.com/obra/superpowers
Ponytail: https://github.com/DietrichGebert/ponytail

Analyze: grill-with-docs, diagnosing-bugs, systematic-debugging, brainstorming.
Plan: to-spec, to-tickets, writing-plans.
Implement: implement, implement-spec, test-driven-development, using-git-worktrees, subagent-driven-development, ponytail (minimal implementation guidance).
Verify: verification-before-completion.
Review: code-review, requesting-code-review, receiving-code-review, retro.

**Important:** Original skills can require extra capabilities/plugins/issues/subagents. Only the skill directories are installed by this package. Ponytail native plugin activation, mode switching and lifecycle hooks are NOT installed; for complete Ponytail functionality install its official host plugin following README instructions. Treat unsupported subagent and background functionality as unavailable, and use sequential fallback. CRG is intentionally not installed or modified by this package.
