# task-orchestration

Follow AGENTS.md and docs/WORKFLOW.md. Use this skill only when the current task needs its expertise.

1. Break down requested change into testable tasks and dependency edges.
2. Review scope overlap; no parallel dispatch on conflicting files or shared mutable resources.
3. Confirm Plan approval and hashes before creating handoff.
4. Route to implementer, then independent verifier and reviewer; never skip gates.
5. Mark unresolved blockers and bring changes in scope back for approval.
