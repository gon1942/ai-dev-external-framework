# ui-quality

Follow AGENTS.md and docs/WORKFLOW.md. Use this skill only when the current task needs its expertise.

1. Confirm existing design system, tokens, screen states and user journeys before changes.
2. Check semantic HTML, contrast, focus, keyboard navigation and form feedback.
3. Test loading/empty/error/success states and responsive widths.
4. Capture screenshots or browser test traces when available. Visual check is not replaced by code review.
5. Do not apply an unrelated visual redesign without approval.
