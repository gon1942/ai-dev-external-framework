# 제품·서비스 설계문서 (design-docs)

**목적:** 구축 대상 프로젝트의 현재 설계 정본. 실제 문서는 프로젝트별로 필요한 영역만 추가합니다.

추천 분류(필요한 경우에만 생성): `architecture/`, `backend/`, `frontend/`, `database/`, `api/`, `security/`, `infrastructure/`.

- 문서에는 상태(초안/승인/폐기), 담당 범위, 마지막 검토 날짜, 관련 Spec·ADR 링크를 기재합니다.
- 공통 프레임워크의 내부 구조는 기존 `docs/architecture/`, 기술 결정 이력은 기존 `docs/decisions/`에 둡니다. 이곳과 중복 정본을 만들지 않습니다.
- 기존 문서가 있다면 파일명과 디렉터리를 유지합니다. 업그레이드는 기존 내용을 수정하지 않습니다.
- 관련 문서만 선택적으로 열고 관련 Task의 Spec/Plan에 참조 경로를 기록합니다.
