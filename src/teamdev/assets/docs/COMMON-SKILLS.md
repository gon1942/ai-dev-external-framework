# 공통 스킬 설치·버전·호출 정책 v0.13.0

- 프로젝트 내 `.ai-dev/skills.lock.json`은 SHA-256 정본입니다. 스킬 원본 `.agents/skills`, 런타임 복사본 `.opencode/skills` 및 `.claude/skills`는 프로젝트별로 동일해야 합니다.
- 기본 설치 시 모든 공통 스킬을 3개 런타임에 배포합니다. 단, 모든 스킬을 매 단계 자동 로드하지 않습니다. 사용은 단계/유형별 조건에 따릅니다.
- 기존 7개 번들 외 통합 스킬 13개는 **원본 외부 스킬을 내려받은 것이 아닌 프레임워크 자체 작성 동등 역할 스킬**입니다. 외부 upstream 구현이나 버전이라고 표시하거나 보증하지 않습니다.
- 외부 upstream 원본을 팀 공통으로 사용하려면 라이선스·리비전·내용 검토 후 패키지를 다시 빌드하고 잠금 파일을 갱신해야 합니다. 현재 패키지는 오프라인 사용 가능합니다.
- `teamdev skills-status --strict`는 세 런타임의 스킬 파일 누락/변경을 검증합니다. `teamdev skills-sync --apply`는 누락 사본만 복구하며 수정된 사본은 `--force`가 없으면 보호합니다.
- `teamdev upgrade-skills --apply`는 기존 프로젝트에서 이전 정책을 백업하고 통합 스킬을 배포합니다. 다른 콘텐츠가 있는 기존 동일 이름 스킬은 덮어쓰지 않고 충돌로 보고합니다.
- 필수 스킬 미설치/해시 불일치는 `teamdev audit --strict`에서 실패 처리합니다. 이는 파일 동등성만 검사하며 모델 로딩이나 실제 호출을 입증하지 않습니다.
- 선택형(웹·보안) 스킬도 배포하되 관련 작업에서만 로드합니다. `playwright-cli` 스킬 파일의 존재는 CLI/브라우저 설치 증거가 아닙니다.
