# ADR 0001: 경량·도구 독립 공통 프레임워크

**결정:** 정본은 저장소 문서와 로컬 CLI에 둔다. 실제 코딩 에이전트 호출은 에이전트 고유 기능을 사용한다. 기본은 단일 작업 순차 처리.

**이유:** 특정 모델/에이전트/프로젝트 이름에 종속되지 않고, 오프라인 동작과 팀 감사 가능성을 확보한다.

**대안:** 단일 거대 에이전트, 모든 것을 중앙 서버에서 실행, 모든 외부 도구 기본 설치 — 추가 복잡도 및 공격 표면 때문에 기본값에서 배제.

**결과:** 자동 파견, SSO 승인, 다중 사용자 동시성 락, CI 결과 증명은 별도 통합 과제. 초기 CLI의 PASS 값은 정직한 증빙 프로토콜 보조 수단에 불과.
