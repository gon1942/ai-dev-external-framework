# 설계: 작업 계약과 에이전트 실행의 분리

- **정본:** `docs/`와 `.ai-dev/`의 공개 가능한 팀 정책.
- **Coordinator:** 요청 분석, 스킬 선택, Task Graph, 승인 및 결과 통합.
- **Implementer:** 승인 범위 안에서 코드와 테스트 수정, 원본 증거 제출.
- **Verifier:** 구현자와 독립적으로 명령 실행/AC 검증.
- **Reviewer:** 변경 내용을 독립적으로 검토. 리뷰는 검증과 다른 역할.
- **Runtime adapter:** 각 에이전트의 파일 포맷과 기능에 맞게 설정. 동일한 권한/병렬 지원을 가정하지 않음.
- **CLI:** 정본 파일과 흐름 상태 관리. 실제 에이전트 시작이나 CI·인증 기능이 아님.

`AGENTS.md`는 항상 적용되는 최소 규칙, 각 `SKILL.md`는 상황별 지침입니다. 컴팩션/RTK는 원본 증거를 대체하지 않습니다.
